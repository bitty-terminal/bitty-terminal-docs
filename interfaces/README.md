# Interfaces

Index of the terminal-platform interface contracts. Normative detail lives
in the linked pages; this index carries no duplicate normative prose.

| Document                                                    | Status | Purpose                                                                      |
| ----------------------------------------------------------- | ------ | ---------------------------------------------------------------------------- |
| [Command-line interface](cli.md)                            | Draft  | Extensible CLI, runtime control, output, and introspection contracts.        |
| [Rich content and presentation interfaces](rich-content.md) | Draft  | Terminal truth, rich blocks, semantic sources, and presentation composition. |

## Authority and status

Both pages are pre-implementation contracts. Accepted detail is recorded in
the [CLI Contract RFC](https://github.com/bitty-terminal/bitty-terminal-docs/blob/main/specifications/cli-contract-rfc.md)
and the [Rich Presentation RFC](https://github.com/bitty-terminal/bitty-terminal-docs/blob/main/specifications/rich-presentation-rfc.md);
these interface pages must not be read as released behavior.
