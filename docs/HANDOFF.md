# Documentation process handoff

Cross-session handoffs for this repository are recorded in CarryCtx (task
handoffs, checkpoints, and progress notes), not in file-based logs. No
file-based handoff log is maintained here.

Shared cross-project handoff records live in
[bitty-docs](https://github.com/bitty-terminal/bitty-docs/blob/main/docs/handoff/README.md).
