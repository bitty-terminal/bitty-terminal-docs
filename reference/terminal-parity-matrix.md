# Terminal parity matrix

## Status and provenance

- Status: **draft**. This page is a lookup reference, not a stability
  promise or a roadmap commitment. No row is a stable or supported public
  contract; the owning configuration contracts remain `Proposed` under
  `OQ-010`.
- Scope: the user-visible configuration and feature surface of Ghostty
  (its configuration reference is the primary comparison axis), plus
  notable Kitty and WezTerm options that have no Ghostty equivalent. Selected
  terminal behaviors also use xterm as a reference peer.
- Evidence rule: a row is **implemented** or **partial** only when the
  `bitty` repository contains the named configuration key or behavior, a
  code path, and a test that exercises it. Every other row is **planned**
  (a specification in this corpus covers it), **gap** (no owning
  specification or code), or **wont-do** (out of scope by design).
- Source revision: the matrix was first extracted from `bitty` `main` at
  `7d7ec91b` (2026-09-30). That revision is **not** an ancestor of the current
  `main` (the history was rewritten), so it is kept only as the original
  extraction provenance and describes no current tree. **Re-baseline
  (2026-11-17, `bitty` `v0.0.44`@`7b3d3df`, `main`@`67f51b56`):** every
  `path::test_name` citation in the matrix was re-checked against the tagged
  tree at the file/name level, and the rows whose evidence no longer resolved
  were corrected — the retired `bitty-compat-lab` crate (`App cursor shape`,
  `Wide / grapheme width`), the renamed Kitty image tests
  (`Kitty graphics protocol`), the relocated session round-trip test
  (`Session save / restore`), the `copy_mode` / search rows, whose Core
  keymap actions retired and are no longer user-reachable
  (`Copy mode (keyboard)`, `Scrollback search`), and three rows whose recorded
  gap or key had changed (`Background image opacity`,
  `Background image position`, `Multiple OS windows`). Rows that still resolve
  unchanged were not re-run, so this remains file-and-test-name evidence, not
  a new execution record. The Shift+Enter evidence is point-in-time evidence
  from the unmerged `bitty` PR
  [#2628](https://github.com/bitty-terminal/bitty/pull/2628) at `9d9eb684`;
  when code and this page disagree, the code wins and this page needs a fix.
- Merge state: the iTerm2 row cites the CTX-1590 task branch (`19a50380`,
  hardened in `26ce4f72`, `b6fb2a65`, and `cfdd0f8f`) merged to `origin/main`
  as squash `8f206dd8`; it is `implemented-only` with no release yet, not
  shipped. Details are in the
  [Image Protocol Decision](../specifications/image-protocol-decision.md#admission-record-2026-10-26).
- The ligature row cites unmerged `bitty` PR
  [#2732](https://github.com/bitty-terminal/bitty/pull/2732) at branch head
  `c87f1307` (2026-10-27, CTX-1607); it is `implemented-only` until that PR
  merges and keeps its fallback qualifier because `crossfont` has no shaping
  stage.
- Key-level detail (types, defaults, ranges, reload class) lives in the
  [configuration options reference](configuration-options.md); escape
  sequence behavior lives in the
  [terminal compatibility matrix](compatibility-matrix.md). This page only
  records parity status and links there.

## How to read the matrix

| Column   | Meaning                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| Feature  | User-visible capability, named neutrally.                                                                              |
| Peers    | `G` Ghostty, `K` Kitty, `W` WezTerm, `X` xterm. A peer listing does not imply matching semantics.                      |
| Bitty    | Bitty configuration key, keymap action, or behavior, when one exists.                                                  |
| Status   | `implemented`, `partial`, `planned`, `gap`, or `wont-do`.                                                              |
| Evidence | Repository-relative `bitty` path and test name for implemented/partial rows; a specification link or reason otherwise. |

Test names are `path::test_name`. Paths are relative to the `bitty`
repository root.
